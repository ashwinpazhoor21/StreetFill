StreetFill: UI mockups (v1 design review)

Prepared 15 November 2026 · Companion to product-plan.md · Screen numbers match the screen inventory (section 3)
These are design mockups, not screenshots of a working app. Nothing has been built. All sample data is invented to show the design: a runner based in North Center, Chicago, 8.4% of the city, 61% of North Center, the "Morning Run" of Sunday 15 November that added 9 streets, a generated lakefront loop to Montrose Beach, and friends Priya, Marcus and Jen. The same numbers are used on every screen. Maps are stylized street grids, not real geography. The frames follow iOS 26 conventions: floating glass tab bar, large titles, sheets, inset grouped lists. They are drawn at 390 × 844 points. Releases: S01–S15 are v1. New screens S16–S25 carry a release tag (green v1, purple v1.1) under the recommended phasing, Option B. Highlight photos are illustrated placeholders for real photos.
Run (thick, solid) Not yet (thin, dashed) New this run (blue, white centre dashes) Marked by you (hollow) Path or trail run (dotted) Generated route, new to you (green, white dots) Generated route, run before (green dashes)
Line styles differ in weight and dash pattern as well as colour (orange against blue against grey), so the map still reads in grayscale and for the common forms of colour blindness.
